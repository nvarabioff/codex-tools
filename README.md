# Codex Tools

A collection of small browser-based tools built with Codex. Each project is self-contained and can be opened directly in a modern browser; no installation or build step is required.

## Projects

### Fantasy Hockey VORP Draft Board

Calculate fantasy hockey player rankings for a custom points league using skater and goalie projection CSV files. Configure scoring and roster settings, compare value over replacement (VORP), track drafted players, save league presets, and export rankings.

- Open [`fantasy-hockey-vorp/index.html`](fantasy-hockey-vorp/index.html)
- See its [README](fantasy-hockey-vorp/README.md) for CSV formats, scoring setup, and details.

### Touchline — Lineup Studio

Build soccer lineups using three formations. Manage a squad and substitutes, save reusable squad lists, and keep the data in browser local storage.

- Open [`soccer-lineup/index.html`](soccer-lineup/index.html)
- See its [README](soccer-lineup/README.md) for usage and data-storage details.

## General notes

- The tools run locally in your browser and do not require a server.
- Saved settings and other persistent data are stored in browser local storage, where applicable. They are specific to that browser profile and device.
- Check each project's README for its own features, inputs, and limitations.
